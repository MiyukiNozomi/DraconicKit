# NodeJS scripts for building svelte

Hello there! this folder is full of scripts that are invoked through CLI, think of them as functions, where their input parameters come in as JSON, and come out as JSON, all through CLI.
You shouldn't really attempt to, you know, run these scripts manually (unless, of course, you're individually testing them).
They're also written in plain JavaScript because, TypeScript here is a bit unnecessary, JSDoc can give us typings, so we're fine.
