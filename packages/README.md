# DraconicKit Packages

- `core` - contains the web server, WebSockets, user APIs, the draconic builder, and JVM hotswap logic.
- `esper` - is DraconicKit's JavaScript engine and NodeJS ESM resolver for the svelte compiler and future server side rendering (work in progress).
- `node-interop` - is a daemon used temporarily to run the svelte compiler and config file in the mean time of `esper`s development.
- `shinkujs` - is the client side hotswap module used in the browser (work in progress).
